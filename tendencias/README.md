# tendencias/

Material de pesquisa (compilado pelo Dr. Ícaro ou gerado pelos subagentes abaixo), que o subagente `curador-tendencias` lê para fazer a seleção.

- Nome dos arquivos: `AAAA-MM-DD-assunto.md` (por exemplo, `2026-10-25-reels-dor-no-joelho.md`).
- O `curador-tendencias` só lê esta pasta: nunca altera nem apaga arquivos daqui.
- Os subagentes `pesquisador-tendencias`, `observador-instagram` e `analista-viralizacao` também salvam relatórios aqui, com os nomes definidos em cada um.
- O subagente `pesquisador-cientifico` salva aqui os relatórios de evidência científica, nomeados `AAAA-MM-DD-evidencias-assunto.md` (por exemplo, `2026-10-25-evidencias-dor-na-canela-corrida.md`). Arquivos com `-evidencias-` no nome são relatórios científicos e não substituem o material de tendências e formatos.
