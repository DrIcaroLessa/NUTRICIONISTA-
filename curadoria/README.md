# curadoria/

Seleção feita pelo subagente `curador-tendencias` a partir do material de `tendencias/` ou colado na conversa: fontes escolhidas, formas escolhidas e o que evitar.

- Um arquivo por rodada, nomeado `curadoria-AAAA-MM-DD-tema.md` (por exemplo, `curadoria-2026-10-25-dor-no-ombro-musculacao.md`).
- Arquivos anteriores nunca são sobrescritos.
