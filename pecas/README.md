# pecas/

Peças visuais montadas a partir de textos já aprovados pelo Dr. Ícaro, pelas skills `criar-peca` (Claude Design) e `criar-peca-canva` (Canva). Tudo aqui é rascunho para aprovação: nada foi publicado, agendado, enviado nem compartilhado.

- Uma pasta por peça, nomeada `AAAA-MM-DD-formato-tema/` (por exemplo, `2026-10-26-carrossel-dor-no-joelho/`).
- Dentro dela, `peca.md` com o link do design, o texto aprovado usado, a lista de arquivos exportados, o que não pôde ser exportado e o resultado da revisão; e os arquivos exportados.
- Pastas anteriores nunca são sobrescritas; se o nome já existir, acrescenta-se `-2`.
